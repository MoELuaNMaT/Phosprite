# Phosprite UI 视觉规范 · 阶段四执行记录

## 范围

基于 Stage 3 分支，阶段四覆盖调色板、UI1 窄工具选项列、UI4 停靠布局与动画时间轴的原生控件。保持 Stage 3 的 UI3 胶囊、调色卡及其布局约束。本轮只改可见材质与绘制，**不改**绘画、取色、选区、图层排序、帧排序或撤销的数据交易。

- **调色板**：`PaletteSwatch` 使用独立 `Control._draw` 生成 R4 像素轮廓。32px 触控单元内显示 28px 色面；像素主题的网格间隔为 0，而单元内部各留 2px，故相邻色面视觉间距 4px。透明棋盘按圆角剪切；主色使用蓝色外环，副色用角标。未改变颜色 RGBA 数值或原有的选中判断。
- **动画视图**：`CelButton` 的 R6 帧格、`FrameButton` 的帧号、`LayerButton` 的图层行与可见/锁定键，以及原生 Timeline 工具栏、图层混合模式下拉框均按同一色彩与描边 Token 绘制。仍使用原始 36×36 帧单元与触摸目标。
- **单帧视图**：保留 `SingleFrameLayerCard` 的独立选中状态与滑动多选逻辑，采用像素选中外轮廓。设置窗、创建图层键和混合模式下拉框统一使用 R6。
- **UI1**：现有 `ValueSlider.configure_tool_vertical_drag()` 保留竖向手势、数值范围、增量和信号，只在像素主题中使用 R6 横向搓动胶囊材质；箭头画线改为像素对齐。
- **UI4**：左右停靠模块和底部 Timeline 使用统一像素面板材质；调色板与取色器的原始分割手柄增加三个竖向像素点，不改变拖拽目标范围。
- **共享底层**：`PhospriteStage4Chrome` 缓存材质，保存原始控件样式并支持切回 Legacy；`PhospriteDraw` 只处理绘制形状，不进入调色板数据模型。

## 约束与风险

1. 仅 Sunny Cream / Twilight Berry 采用新样式；旧主题和自定义主题仍保持旧样式。
2. 像素描边沿用设置中的 1px、2px、3px 选择；不再新增独立设置。
3. 只使用最近邻采样的透明度、边框和整数绘制；不改变字体，使既有 iPad 中文字符回退链继续有效。
4. 不能改变图层长按 450ms / 上下拖拽排序的生命周期修复。本阶段的图层按钮只改 StyleBox，不能更改 `LayerTouchAdapter` 或 `Project.move_layers`。
5. UI4 的 `Palette`/取色器分割比例继续保存在原来的 `ui4.palette_split_ratio` 中。
6. 严格禁止因更大像素描边把帧单元、触控区或停靠尺寸撑大。

## 验收

自动检查：`static-checks.yml` 的 gdformat、gdlint、字体/多语言覆盖；`regression-tests.yml` 的导入、真实编辑器启动、UI3 项目切换及全部单元/集成测试。

人工验收：在 iPad 横屏和竖屏，对比原生、Sunny Cream 和 Twilight Berry；测试透明/黑/白/半透明色块，主副色取色，空色块连续点击，色块长按移动，UI1 竖向数字拖拽，UI4 竖向分割拖拽，动画/单帧切换、帧选择、图层上下移动与撤销重做。重点复测两层时将下层拖到上层无闪退。

本轮不负责剩余 78 枚 Q 版图标的全部美术替换和真实 iPad 签名安装。这两项留给后续独立的设备验收与资产替换阶段，不能用 headless 通过替代。
