# Phosprite mode icons — Material Design Icons (MDI)

These nine SVG files originate from the open-source **Pictogrammers / Material Design Icons** project:
https://github.com/Templarian/MaterialDesign-SVG

Original artwork (each file is under `svg/` in that repository):
- `selection.svg` — selection / replace
- `vector-union.svg` — selection / add
- `selection-remove.svg` — selection / subtract
- `vector-intersection.svg` — selection / intersect
- `layers-triple.svg` — eyedropper / top visible composite
- `layers.svg` — eyedropper / current layer
- `selection-search.svg` — bucket / similar contiguous area
- `palette-swatch.svg` — bucket / similar colors
- `select-all.svg` — bucket / whole current selection

All icons retain the original path geometry. The root SVG fill was set to white
(`#ffffff`) for legibility on Phosprite's dark tool-option button backgrounds.
The icon filenames are retained to make upstream attribution unambiguous.
