# Gradient mode icon assets

Files in this directory are adapted from the open-source Material Design Icons SVG set by Pictogrammers / Templarian, available at:
https://github.com/Templarian/MaterialDesign-SVG

Icon names: gradient-horizontal, radius, grid-off, repeat-off, repeat, mirror, crop, selection-search, selection-multiple, selection.

Source licensing: Apache License 2.0. See https://github.com/Templarian/MaterialDesign-SVG/blob/master/LICENSE and https://www.apache.org/licenses/LICENSE-2.0.

Adaptation: added 24x24 dimensions and a light fill color for Phosprite's UI.
Bayer matrix icons are the existing Phosprite assets in assets/dither-matrices/.
